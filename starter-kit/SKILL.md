# 图文成片（无 API · 纯本地渲染）

## 你要产出什么
一个 `script.json`，然后跑 `make_video.py` 得到 1080×1920 的 MP4。不要写别的渲染脚本。

## 工作流
1. **确认素材**：问用户图片在哪（或先跑 `tools/make_placeholders.py` 出占位图）。
   图片建议 9:16（1080×1920）。一张图够，几张图更好。
2. **写文案**：一条镜头一句话，句子 ≤ 14 字（3–4 秒说完）；标题 ≤ 10 字。
   * 情感/感悟：口语、短句、留白，最后一句给"钩子"或"态度"。
   * 科普/知识：先抛反常识结论，再给机制，最后给行动建议；不要编数据。
   关键词用 `**两个星号**` 包起来，会自动高亮 + 放大 8%。
3. **生成 script.json**：字段与示例见本目录 `examples/script.gushi.json`（情感风格）。
4. **渲染**：
   ```bash
   pip install -r requirements.txt
   python3 tools/fetch_fonts.py            # 首次：拉中文字体
   python3 make_video.py script.json -o out/final.mp4 --srt --cover
   ```
5. **交付**：报成片路径 + 时长 + 体积；同时给 `.srt`（方便后续单独改字）和封面图。
   如果用户要配音，告诉他用 edge-tts 生成 mp3，再把文件路径写进每镜的 `voice` 字段。

## 铁律
* 不要联网调用任何生成模型的 API；画面只来自用户给的图。
* 不要把 libass/drawtext 当成烧字方案——中文会变豆腐块（原因见 make_video.py 注释）。
* 一次别塞超过 3 层 overlay；图层多了改分批（脚本已内建）。
* 文案不许编造事实；科普内容提醒用户标注来源。
